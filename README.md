# Model's Birthday Website

A responsive, burgundy and rose-gold birthday website celebrating Model's 24th birthday on 6 November 2026.

## Overview

This static HTML website presents a polished birthday celebration experience with an elegant color palette, mobile-friendly layouts, and accessible interactions.

## Live site

[View the birthday website](https://aethertimi-ctrl.github.io/birthday-website/)

## Built with

- HTML5
- CSS
- JavaScript

## Local preview

Open `index.html` directly in a browser, or serve the repository locally:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.

## Project structure

The main website files live at the repository root. A typical static GitHub Pages deployment uses `index.html` along with the accompanying CSS, JavaScript, and image assets.
